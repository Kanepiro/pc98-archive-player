# TASL PC Boost (prototype, 0.1)

**PCブーストは、既存のブラウザー変換とは別のC++ネイティブ変換経路です。**
ブラウザー版を置き換えたり、既存の変換や途中保存を壊したりしません。
WindowsとLinuxで利用する構成です。

## Windows 10/11 (64bit)

1. GitHub Actions の「PC Native Boost (Windows x64)」実行後にできる
   `TASL-PC-Boost-Windows-x64` アーティファクトの ZIP を展開します。
2. ZIP 内の `TASL-PC-Boost.exe` を起動し、黒いコンソール画面を開いたままにします。
   管理者権限やPythonの別インストールは不要です。
3. 同じPCのChrome/Edgeで
   `https://pc98-archive-player-seven.vercel.app/` を開き、
   「動画 → TSL」画面で **PCブースト（PC専用・C++ネイティブ）** にチェックします。
4. 動画と画質設定を選んで通常の「変換」を押します。
5. 終了時は補助プログラムのコンソールを閉じてください。

補助プログラムが見つからない場合は、起動状態とChrome/Edgeの
「ローカルネットワーク接続」の許可を確認してください。
別のPCにインストールした補助プログラムには接続できません。

## Linux 開発・検証

```sh
python3 generate_glyphs.py
g++ -std=c++17 -O3 tsl_boost.cpp -o tsl_boost
python3 bridge.py
```

FFmpeg と FFprobe がPATHに必要です。

## しくみと制約

- 入力動画はブラウザーから同じPCの `127.0.0.1:39083` に送信します。
  動画の中身を外部サーバーへアップロードする処理はありません。
- FFmpegが動画を**連続デコード**し、別プログラムのC++が
  輪郭・明暗を分析してTSL（Shift-JIS/CP932）に書きます。
  フレームごとのブラウザーseek、MediaPipe、WebGPU Workerには依存しません。
- モード3・4はブラウザーと**異なる近似アルゴリズム**であり、
  モード4は指定された272文字のうちの一部だけを使用します。
  顔・動物の認識モデルや元のAA組版と同一の画質を保証しません。
- **現在のPCブーストはCPU主体**です。GPUで文字照合する実装ではありません。
  FFmpegのデコード経路も本版ではCPUが基本です。
- アプリのPC-98実寸「元動画解像度÷16」、16ドット文字設定、
  文字パレット、fps、切り抜き位置は維持します。
- 最大入力2GB・2時間、出力10,000画面・192MiBに従います。
  長尺時は従来同様に生成fpsが減ることがあります。
- ブースト側にはまだ途中保存・再開がありません。
  中断するとそのジョブは最初からやり直します。
- 「MP4へ直接変換」のMP4書き出しは、TSL生成後に従来の
  ブラウザー側で行います。PCブーストが速くするのはTSL生成工程です。
- 一時ファイルのため、動画ファイル+TSL分のPCの空き容量が必要です。
- 補助プログラムはループバック限定で起動し、アクセス元はアプリの
  公開ドメインまたはローカル開発ホストに制限しています。
- 既存のブラウザー変換には一切影響しません。PCブーストのチェックを
  外せば通常の変換経路です。

**現時点では試作品です。Windows 10実機・画質の視覚比較・
大容量の速度実測は未検証です。公開版には自動反映しません。**
