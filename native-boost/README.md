# TASL PCブースト — GPU対応 Windows版 v1.1

PCブーストは、ブラウザー版と**独立したPCネイティブ変換エンジン**です。
FFmpegが映像を連続デコードし、最適化したC++コードがモード別の文字アニメ（TSL）を生成します。
既存のWeb版を変更せずに使える、同梱プレーヤー付きのポータブルWindowsアプリです。

## Windows 10/11（64bit）で使う

1. `TASL-PC-Boost-Windows-x64.zip` を**全部展開**してください。
   EXEだけを取り出すとFFmpegやプレーヤーが動きません。
2. 展開したフォルダーの **`TASL-PC-Boost.exe` をダブルクリック**してください。
   管理者権限、Python、Node.js、Vercelログインは不要です。
3. Chrome/Edgeなどの標準ブラウザーが開きます。開かなければ
   **http://127.0.0.1:39083/** を同じPCで開いてください。
   EXEが表示する黒いコンソール画面は、変換中は閉じないでください。
4. 「動画 → TSL」→動画選択→モードと画質設定を選択します。
   PCブーストのチェックは最初から入っています。「変換」を押します。
5. 完了したら「TSLをダウンロード」。プレーヤーで再生も可能です。
   変換終了後はEXEのコンソール画面を閉じて構いません。

## 変換エンジン

- モード1：明暗の高速文字化（ASCII）
- モード2：PC-98式の丸い5階調網点（Shift-JIS）
- モード3：輪郭構造を見てPCネイティブ字形照合（Shift-JIS）
- モード4：**指定の272文字をすべて候補にした**輪郭・字形照合（Shift-JIS）

モード3・4の高速ネイティブ実装は**ブラウザー標準版とは別の画像アルゴリズム**です。
そのため、画質や使用文字の傾向は完全一致しません。
TSL生成は最適化したC++ CPU処理です。MP4のH.264エンコードはGTX 1050 TiなどのGPUでNVIDIA NVENCを優先します。
GPUが使用できない場合はlibx264 CPUへ自動切り替えし、実際に使用したエンコーダーを画面に表示します。
本版には標準モード4のMediaPipe顔認識モデルと同じ分析は含まれません。
PC-98実寸では元動画の幅・高さをそれぞれ16で割った文字数を採用。
全角16×16ドット、半角8×16ドットの再生フラグをTSLヘッダーに保存します。

## 長い動画・中断からの再開

- 上限：入力2GB・4K・最長2時間。TSLは最大10,000画面・192MiB。
  長尺時は指定fpsから画面数を自動調整します。
- 途中までのTSLはPC側のディスクに蓄積します。
  16画面ごとに確定させ、処理が止まっても完全なフレームから再開します。
- ブラウザーのタブを閉じても、EXEを閉じない限り変換自体は継続できます。
  ブラウザーを開き直し、同じ動画を選んで同じ設定で変換すると実行中の作業に再接続します。
- EXEまで閉じてしまった場合も、**同じ元動画と変換設定を選び直す**と保存済み部分から再開できます。
  元動画の再転送と先頭からのFFmpeg読み込みは行われますが、完成済みの文字化は再実行しません。
- 途中・完成キャッシュの保存先は `%LOCALAPPDATA%\TASL-PC-Boost` です。
  未完了の動画コピー・完成したTSLが入ります。不要になった後は、
  EXE停止中にそのフォルダーを手動で整理できます。
- 「MP4へ直接変換」をONにすると、Win32 GDI文字描画→FFmpeg **GPU NVENC**によるH.264 MP4を生成します。
  **元動画の音声もAACで収録**。GPU未対応時は自動でCPU変換します。
  PCネイティブではブラウザー版の5分制限を適用せず、入力上限の2時間まで扱います。
- GTX 1050 Ti（Pascal世代）にNVENC API互換性がある **FFmpeg 8.1.2** を同梱。
  新しいFFmpeg 9系では古いNVIDIAドライバーのNVENCが使えない事例があるため、9系へ自動更新しません。
- **GPUで高速化するのはTSL→MP4エンコード部分**です。TSLへの文字化はCPUネイティブ処理のままです。
  動画の長さや文字描画の負荷によって総処理時間の短縮率は変わります。
  WindowsタスクマネージャーではMP4書き出し中にGPUの「Video Encode」を確認してください。

## 安全・注意点

- 動画は同じPC内（ループバック127.0.0.1）のみで送受信します。
  外部への動画アップロードは行いません。
- このアプリは**コード署名なし**で配布されています。正規の配布物と
  チェックサムを確かめてから実行してください。
- Windows実機相当のChrome操作とMP4/H.264/AACのテストはGitHub ActionsのWindowsランナーで実行。
  ただしWindowsランナーにはGTX 1050 Tiがないため、**1050 Ti実機でのNVENC性能は未実測**です。
  PC個体のCPU性能・動画内容による速度と見やすさには差があります。
- ブラウザー版は「PCブースト」のチェックを外せば従来どおり利用できます。
  PCブーストが無いモバイル端末では通常の変換を使用します。

## 開発・Linux実行

このソースの `native-boost` ディレクトリー内で:

```sh
python3 generate_glyphs.py
g++ -std=c++17 -O3 tsl_boost.cpp -o tsl_boost
cd ..
npm ci
npm run build
cd native-boost
python3 bridge.py
```

PATH上に `ffmpeg` と `ffprobe` が必要です。
自動生成したグリフ特徴量は別途同梱フォントを必要としません。
