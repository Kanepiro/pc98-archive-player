TASL Archive Player

Windows ネイティブ版 · v0.3.41

Windows 10 / 11で使う

Windows x64用ZIPを展開し、TASL-PC-Boost.exeを起動してください。PythonやNode.jsの追加インストールは不要です。

Windows版 v0.3.41 ZIPをダウンロード

モード1〜4すべてでWindowsネイティブGPUを優先します。GPU非対応・実行失敗時は元のCPU処理へ自動で切り替えます。

配布ファイル・SHA-256・リリース詳細 · Google Drive保存先（所有者向け）

処理方式

  • 変換はPC内で完結。127.0.0.1の画面はPC内のEXEの操作画面です。WebGPUには依存しません。
  • モード1・2：画素集約・濃淡変換・輪郭強調をDirectComputeで計算します。
  • モード3：色補正・ぼかし・輪郭抽出と連結・字形照合・ちらつき抑制・文字配置をDirectComputeで計算します。
  • モード4：Direct3D 11 / DirectComputeによる輪郭解析・272文字の字形照合・全体組版を優先。対応環境では顔・物体認識にDirectMLを使用します。
  • 失敗したGPU工程はCPUへ切り替え、理由を表示・記録します。入出力、文字列の組み立て、GPUへの指示はCPUが担当します。
  • 動画からのMP4直接出力はDirectCompute描画とFFmpeg / NVENCを優先。非対応時はCPUへ切り替えます。
  • 基本アルゴリズムと文字パレットを維持。GPUとCPU、Windows版とスマホ版の選択文字は完全一致を要求しません。

検証範囲

Windows CIでネイティブビルド、WebGPUを無効にした全モードの変換、モード1・2の階調、モード3の輪郭・字形誤差・移動・途中再開、CPU切り替え、モード4の272文字と全体組版品質、TSL・MP4、梱包EXEを検証。記録はZIP内のVALIDATION-REPORT.mdとVALIDATIONフォルダに同梱しています。

DirectComputeの実行試験には明示的なWARPソフトウェアアダプターを使用しています。GTX 1050 Ti・実機DirectML・NVENCの動作や高速化率は未検証です。全機種での検証を前提にはしていません。
