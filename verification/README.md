# 実行検証結果（2026-11-03 JST）

検証環境: Ubuntu x64 / Chrome / Node.js 22.22.1 / Emscripten 3.1.69。画面サイズ390×844、タッチ入力を模擬。Android実機ではありません。

| 試験 | 結果 | 確認範囲 |
|---|---|---|
| MAG 48件 | デコード成功 | 全件の寸法・RGBAハッシュ記録。原機との全件照合は未実施 |
| TSL 15件 | パース成功 | 全フレームと再生スケジュール。1178画面の作品を含む |
| MMS 42件 | 生成成功 | 各冒頭5秒、既定のキー未入力経路 |
| ALV_MM03.MMS / ESP_NAD0.MMS | WebAssemblyとネイティブ出力一致 | 冒頭5秒の全映像・PCMのSHA-256一致 |
| 重点MMS 2件 | ブラウザー10秒再生、欠落0 | 映像表示・音声供給を確認。全編と原機同期は未確認 |
| オフライン | 成功 | キャッシュ後に通信を切断し再読込・自作MMS再生 |
| 不正MMS | エラー処理成功 | ページのクラッシュなし。その後正常MMSを再生 |
| 原資料の変更 | なし | 別の作業領域でコピーを使用 |

自作12秒テストの通常再生: 706表示フレーム / 12.02秒、音声欠落0サンプル。音声出力の時刻をperformanceTimeで補間する修正前は566フレーム、修正後は706フレームでした。

負荷試験: 再生中にUIスレッドを毎秒150ms、6秒間停止。音声欠落0サンプル。意図的な停止中の映像は間引かれます。

単体テスト5件成功。MAGの16/256色・圧縮フラグ・不正境界、TSLの時刻境界と長編、PCMブロック境界を検証しました。

音声欠落0はAudioWorkletのバッファー充足の計測結果です。Androidの物理スピーカーからの出力を録音・聴取した結果ではありません。全件の「正常鑑賞」判定にはしていません。

機械可読結果: corpus-results.json、browser-results.json、native-wasm.json。元作品とそのキャプチャーは配布しません。
