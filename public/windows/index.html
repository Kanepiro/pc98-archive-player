Windows ネイティブ版 · v0.3.44

Windows 10 / 11で使う

Windows x64用ZIPを展開し、TASL-PC-Boost.exeを起動してください。PythonやNode.jsの追加インストールは不要です。

Windows版 v0.3.44 ZIPをダウンロード

モード4を、少ない文字と空白で輪郭を描く60pxのAAアニメーションへ更新しました。指定170文字を比較し、合格した文字だけを置きます。

配布ファイル・SHA-256・リリース詳細

v0.3.44の変更点

  • モード4は60×60pxのマスで処理。1920×1080は32×18マス、1080×1920は18×32マスです。端数は余白で処理し、切り抜きません。
  • ぼかし・輪郭抽出・字形の比較を行い、輪郭がない場所や似た文字がない場所は空白にします。
  • Noto Sans Mono CJK JP Regularを同梱。文字選択・プレビュー・TSL再生・MP4出力で同じフォントを使います。
  • モード4の字形照合と描画はWindowsネイティブGPUを優先し、利用できない場合はCPUへ切り替えます。WebGPUには依存しません。
  • 動画の連続読み取りと途中再開を確認。モード1〜3の変換方式は変更していません。

確認した動作

Windows 10 / GTX 1050 Tiで、22秒・24fps・528フレームの変換とMP4出力を確認しました。18秒以降も映像が更新され、合格条件に反する文字は0マスでした。TSL保存・プレビュー・再読み込み後の復元も確認しています。

Windows 11実機は未検証です。GPU描画後のMP4エンコードは、検証環境ではCPUを使用しました。細かな顔や重なった人物では、輪郭が途切れる場合があります。

更新するとき

旧版とは別のフォルダへZIPを展開し、新しいTASL-PC-Boost.exeを起動してください。旧版を起動中の場合は先に終了してください。画面のバージョンがv0.3.44になっていることを確認できます。

既存TSLを再生できます。v0.3.44のモード4で保存した文字位置を正確に再生するには、プレーヤー側もv0.3.44へ更新してください。旧方式のモード4途中データは引き継がず、新しい方式で変換し直します。
