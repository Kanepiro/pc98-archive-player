# 公開版高速化候補 v0.3.45-rc.1 — 実装記録

## 改修元

リポジトリ: https://github.com/Kanepiro/pc98-archive-player

Windows安定版は windows-v0.3.44 / commit 3f0bd408d3e6f47d1e0ea43ccff33265bcf15b94。Web/PWA公開系統は main / commit aa20464353766735ccf082a10d3344122eec2120。両系統は同一ソースではないため、別clone・別候補ブランチで改修した。ULTIMATE IIは参考資料であり、改修元・性能比較元ではない。

公開リリース、既存配布URL、旧専用版、ユーザーデータは変更していない。候補版は独立ポートとデータディレクトリを使用する。

## 共通処理

モード1〜3は公開版のHTMLVideo seekとCanvas描画、モード4は従来のCanvasSinkを保持。HTMLVideoのシーク・画素取得は従来どおり直列に行う。長尺90秒地点で前のフレームを取り込む不一致が出たため、HTMLVideo取得と変換の重複実行は撤回した。モード4だけはCanvasSinkが保持する独立フレームを1枚先読みする。16フレーム単位のcheckpointと時間状態の対応を維持する。

モード3のGaussian係数を再利用し、行DP配列・セル特徴量の作業領域を行ごとに再確保しない。Float32格納、加算順序、候補順、同点優先順位は保持。もともと棄却される「輪郭エネルギーなし」の非空白文字は、同じ条件式を内積計算より前に移した。

モード4の既存170文字・2014配置のatlasをPromiseで再利用する。CPU経路では同じatlas・同じセルのFloat32特徴量がビット一致する場合だけ、前フレームの結果を再利用する。キャッシュは1フレームに制限する。

## Windowsモード1・2

公開版のDirectComputeを保持。共有メモリ転送、GPUバッファ再利用、必要な入力領域だけのupload、機能別health確認を採用する。モード2を新しいWebGPU実装へ切り替えていない。公開Web版に元からあるWebGPU候補・CPU照合の仕組みは保持。Windows固有コードはWeb/PWAへ持ち込まない。

## Windowsモード3

字形マスクと前フレーム状態をGPUへ保持。通常応答を文字番号中心にし、大きな時間状態を毎フレームブラウザーへ往復させない。checkpoint保存時には完全なtarget/grayを取得する。

前処理・時間状態・候補損失を計算後、独立した行のDPを並列化する。行内順序・比較式を維持し、近似探索や候補削減はしない。

ホストは96 MiBの共有メモリと最新2件の完全状態を保持し、ネイティブ計算失敗時に直前状態をCPUへ渡せる。ホスト自体を失った場合の復旧基盤は永続checkpoint。

## Windowsモード4

公開版の前処理式をC++へ移植。倍精度の演算順序を保つSSE2と行単位の並列処理を使用する。既定スレッド数はhardware_concurrencyを1〜16に制限し、特定PCの6スレッドに固定しない。SSE2実行時判定とscalar切替を用意する。

DirectComputeではatlasを保持し、転置配置とビット一致特徴量キャッシュを用いる。非負項の和という損失式の厳密な下限で勝てないと確定する場合だけ残りの計算を省く。文字・配置・共通の最終採否判定は維持する。

グループサイズは64/128/256、既定128。GPUクロック・ドライバー・電力設定は変更しない。新経路の初期化失敗では既存GPU経路、変換中の失敗ではCPU経路へ戻る。

## MP4

同梱FFmpegと公開版のNVENC p4 / VBR CQ21、libx264 veryfast CRF21、AAC 192kを保持。NVENCは試験エンコードで可否を確認し、失敗時はCPUへ切り替える。

字形lookupと行文字列処理を効率化し、同じ画素のGPU描画とパイプ書き込みを重ねる。1 MiBパイプ、実行ファイルmtime対応のprobeキャッシュ、TSLヘッダー限定読み取りを用いる。端数時間でTSLに1枚余分の最終画面がある場合の欠落を補い、音声側の-shortestによる切り捨ても避ける。

Web/PWAのMP4コーデック、解像度選択、音声処理は変更していない。

## 適用範囲

解像度、FPS、サンプル密度、候補文字数、フォント、判定閾値を高速化目的で下げていない。公開Windows x64の基盤を維持し、AVX/SSSE3/SSE4/FMAを前提にしない。実測結果と検証の限界は別報告書を参照。
