v0.3.46の変更点

縦3:4（1080×1440）・横4:3（1440×1080）の生成モードを追加。モード1〜4に対応し、既存の変換精度とBoost高速化を維持しました。

新2モードは全体表示が初期値。TSL保存・再読込・中断再開と指定解像度MP4に対応します。モード4は縦18×24／横24×18の60pxセル。H.264・8bit 4:2:0・AAC音声・faststartの公開版設定を維持しています。

v0.3.45でのWindows実測

Windows 10 / AMD Phenom II X6 1065T / GTX 1050 Ti。22秒・1920×1080・24fps素材、各2回の中央値。MP4完成までの総時間です。変換はDirectCompute、圧縮は両版ともCPUのlibx264です。
