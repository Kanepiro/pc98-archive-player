処理方式

  • 変換はPC内で完結。127.0.0.1の画面はPC内のEXEの操作画面です。
  • モード4はDirect3D 11 / DirectComputeによる輪郭解析・272文字の字形照合・全体組版を優先。対応環境では顔・物体認識にDirectMLを使用します。
  • 失敗したGPU工程だけCPUへ切り替え、理由を表示・記録します。
  • モード1〜3の専用ネイティブGPU計算は未実装のためCPU処理。全モードでWebGPUに依存しません。
  • 動画からのMP4直接出力はDirectCompute描画とFFmpeg / NVENCを優先。非対応時はCPUへ切り替えます。
  • 画像認識・輪郭・文字幅・272文字パレット・画面全体を評価する基本アルゴリズムはスマホ版と共通。選択文字の完全一致は要求しません。

検証範囲

Windows CIでネイティブビルド、モード1〜4、WebGPU無効時の変換、272文字制限、独立評価式でのモード4品質、TSL、MP4、梱包EXEの起動・認識を検証。結果はZIP内VALIDATION-REPORT.mdとVALIDATIONフォルダに同梱しています。

WARPは検証用のソフトウェアアダプターです。実GPUの速度・使用率を示す数値ではありません。人物・動作の主観的な認識品質と、利用者のWindows 10 / 11端末での互換性は追加確認が必要です。
