# Windows native v0.3.42-rc1 — GPUメモリ常駐・実機検証前

Windows専用の検証候補です。正式配布版v0.3.41の置き換えではありません。
GTX 1050 Ti / Windows 10 実機での速度・VRAM余裕・MP4最終確認は未完了です。WARPの測定値を実GPUの性能とは扱いません。

- 272文字の字形・特徴量・マスク・方向情報・接続端点をジョブ開始時に転送し、同じ字形なら再構築・再転送しません。
- 最大10入力フレームの固定リング領域を追加。追加領域256MiB以下で全10枠を確保できる場合のみ使用します。確保不可時は従来と同品質の経路です。
- GPUアリーナの全消去を作業領域だけの消去に変更。評価式、探索回数、候補条件、輪郭・認識、解像度、fpsは変更しません。
- 確認済み直前フレームの濃淡と文字配置をGPU上で参照し、CPUからの再転送を省きます。
- ジョブ識別・順序チェックにより、他の映像の入力や時間方向の状態が混在しないようにします。
- 転送回数・バイト数、Map待機時間、バッファ確保/解放、追加領域、DXGIプロセス使用量を計測します。
- v0.3.41の元映像・構図保持の修正を継承。スマートフォンのmain・配布URL・変換・UIは変更していません。

10枠は順序を維持する入力保持です。10フレームの独立並列処理は行いません。
輪郭・認識とのプロセス境界を越える中間転送と、criticの既存収束確認の同期は残っています。
同梱VALIDATIONの比較はWindows CIのWARPソフトウェア実行です。実機測定を完了するまで性能向上達成とは報告しません。
