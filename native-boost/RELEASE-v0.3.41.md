# Windows ネイティブ版 v0.3.41

モード4が元映像と違って見える原因となる自動加工を修正しました。

- 顔を追う自動ズームを除去し、選択した切り抜き・構図を保持。
- 顔の元輪郭を消して定型の目鼻・髪・輪郭を描く処理を除去。
- 検出した顔の外側にある人物・手・背景の輪郭を消す処理を除去。
- 顔・物体認識による重要度付け、272文字の字形照合、全体組版を維持。
- モード1〜4すべてのDirectCompute優先、DirectML認識、NVENC/CPU切り替えを維持。
- 旧途中保存との混在を防ぐためモード4の互換番号を更新。修正後は元動画から再変換してください。

Windows CIでビルド・全モード・GPU輪郭保持・CPU切り替え・MP4・梱包EXEを確認するワークフローに合格した場合のみ公開します。DirectCompute実行はWARPソフトウェア検証で、GTX 1050 Ti・DirectML・NVENCの実機性能は未検証です。
