# TASL PC Boost v0.3.42-rc2 — Windows ネイティブGPU版（実機検証前）

GPUメモリ常駐の検証候補です。追加領域は10入力枠＋NMS予約1MiBで256MiB以内。従来の組版と今回の最適化後では文字列・評価値の一致を検証し、動画全体も旧v0.3.41と比較しています。詳細はGPU-RESIDENT-NOTES.mdとVALIDATION/RESIDENT-VALIDATION-JA.mdを参照してください。GTX 1050 Ti実機での確認は未完了です。

ZIPを展開して「TASL-PC-Boost.exe」を起動してください。PythonやNode.jsの別途インストールは不要です。モード1〜4のすべてでネイティブGPU処理を自動選択します。モード1・2の画素集約・濃淡・輪郭強調、モード3の色補正・ぼかし・輪郭連結・字形照合・ちらつき抑制・文字配置をDirectComputeで計算します。WebGPUはどのモードでも使用しません。

モード4の輪郭解析、被写体優先度、輪郭の連結・細線化、元映像の顔・身体・背景の輪郭保持、字形照合、候補選択、行組版、2行同時最適化、全画面評価による修正をDirectComputeで実行します。顔・物体の認識は元のMediaPipeモデルの重みを保持したONNXモデルをDirectMLで実行し、前処理と重複検出の除去にもDirectComputeを使います。WebGPUに依存しません。

元の272文字パレット（余白を加えて273字形）、文字幅、輪郭評価、全画面の評価式を維持しています。GPUとCPUの浮動小数点計算・探索順の違いにより、選択文字は異なる場合があります。

MP4はDirectComputeで文字描画・拡大縮小・余白・NV12色変換を行い、実エンコード試験に成功した場合はNVENCで出力します。失敗した工程は元のCPU処理へ切り替え、画面と記録に理由を残します。文字列の組み立て、入出力、GPUへの指示、ファイル保存はCPUが担当します。

変換終了後の「工程別時間・GPU使用状況を保存」から測定JSONを保存できます。GPU時間はD3D11タイムスタンプ、使用率はnvidia-smiで収集します。取得できない数値は未取得として記録します。

同梱のVALIDATION-REPORT.mdとVALIDATIONフォルダが実測結果です。WindowsのWARPソフトウェア実行検証と、GTX 1050 Ti実機の性能検証は別です。GTX 1050 Ti、実機DirectML、NVENCの動作・速度・使用率は未検証です。WARPの数値を実GPUの高速化率として扱わないでください。

既存の公開サイト・mainブランチ・旧版ZIPを置き換える処理は含みません。

モード4の自動ズームと顔の定型描画を除去しました。認識は元の輪郭の重要度付けに使い、元にない目鼻・髪・輪郭を描き足したり、顔以外の人物・動作を消したりしません。
