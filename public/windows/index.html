v0.3.45の変更点

モード1〜4の処理・メモリ・転送を最適化し、特にモード3とモード4を高速化しました。文字パレット、フォント、変換精度、既存TSL、保存・中断・再開、GPUが使えない場合のCPU切り替えを維持しています。モード4は60px・指定170文字の輪郭AAです。

MP4は従来のH.264/AAC設定を維持し、短尺で欠けていた最後の1フレームを保持します。末尾の圧縮結果と再生長は旧版から変わります。

Windowsでの実測

Windows 10 / AMD Phenom II X6 1065T / GTX 1050 Ti。22秒・1920×1080・24fps素材、各2回の中央値。MP4完成までの総時間です。変換はDirectCompute、圧縮は両版ともCPUのlibx264です。

確認範囲と制限

Windows/Linuxで計104試行、比較52組のTSLは全件SHA-256一致。旧TSL、保存・中断・復元、GPU不可・途中失敗時の切り替えを確認しました。

Windows 11、Android/iOS実機、他のCPU/GPU、NVENC成功経路は未検証です。検証環境ではNVENC初期化に失敗しCPUへ切り替わりました。実行ファイルは署名なしです。細かな顔や重なった人物では輪郭が途切れる場合があります。
