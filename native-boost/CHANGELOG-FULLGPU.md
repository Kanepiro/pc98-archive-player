# v0.3.38 変更履歴

v0.3.37のWindows PCブーストを基に、モード4の主要処理をネイティブGPUへ移行しました。

- 字形照合だけのGPU処理から、全画面を考慮した組版全体のDirectCompute処理へ変更。
- 元の候補パレット、評価式、行DP、2行ビーム探索、画面全体の再評価・採用判定を維持。
- 輪郭の色・輝度解析、連結成分、距離場、被写体優先度、細線化、顔の補正をGPU化。
- 顔・物体の元モデルをハッシュで固定し、DirectML用へ変換。量子化境界を保持。
- 認識画像の前処理、ボックスの復号、顔の重み付きNMS、物体NMSをGPU化。
- MP4の字形描画、拡大縮小、余白、NV12変換をDirectCompute化。NVENCの実動作プローブを維持。
- GPUからCPUへ戻すデータを最終配置・評価値などに限定。GPU作業領域を再利用。
- シェーダーの事前コンパイル、不要になった組版修正ディスパッチの打ち切りを追加。
- 工程別時間・GPU使用状況・フォールバック理由の測定JSON保存を追加。
- 旧版の途中保存と混在しないようチェックポイント識別を更新。
- 元の画面評価式による独立検査、フルHDの組版検査、765字の描画比較、認識後処理、動画全体・MP4出力、梱包アプリの検査を追加。

公開版の更新・リリース公開は行っていません。
