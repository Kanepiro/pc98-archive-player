# MP4書き出し修正 0.2.1（2026-11-03）

## 原因
実物の `ｽﾜﾝ.MMS` を解析したところ、映像は約8.568秒で最終フレームへ到達し、PCM音声も約9秒以内に無音になったが、シナリオはキー入力待ちの状態で終了フラグが立たなかった。ループ作品ではない。旧版は終了フラグだけを待ち、5分で失敗した。

## 対応
- 書き出し用Workerはフレーム追加・PCM非ゼロの最終時刻を追跡。3秒間追加がない場合に、最後の映像・音声から0.6秒の余白を付けて終了する。
- MP4の音声と映像をそれぞれ独立したWorkerでレンダリングし、同時にエンコーダーへ投入。音声だけを先に進めた際のmuxer待ちを解消した。
- AACは音質設定をmediumへ変更。高負荷環境でも処理が進むよう調整。
- この自動停止判定は、途中に3秒を超える意図的な静止・無音がある作品では誤判定し得る。キー入力を必要とする場面の選択・分岐には未対応。

## 実行済みテスト
- 収蔵の `ｽﾜﾝ.MMS` を読み込み、Chrome 152（Linux）でMP4保存成功。`ffprobe` でH.264・640×400、AAC・48 kHz・モノラル、9.365333秒、322084 bytesを確認。元MMSはGitHubに追加しない。
- 自作 `ContinuityTest.MMS`：H.264＋AAC、12.032秒のMP4保存成功。自作MMSが既定のシナリオ終端で終了する動作を維持。
- 合成TSL：無音H.264 MP4生成成功。
- 合成MAG：5秒H.264 MP4生成成功。
- `npm test`：既存5件すべて成功。`npm run build` 成功。
