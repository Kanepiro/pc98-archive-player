# TASL PCブースト — GPU文字変換優先・正規モード4維持版

この版は、**元のPC-98 Archive Player v0.3.35のモード1〜4を正本として使用**します。
前回の別アルゴリズム版とは異なり、モード4の顔・物体認識、主輪郭抽出、
272文字の候補、全体組版、文字配置の再評価を一切置き換えません。

**PCブースト有効時は、対応した実GPUが利用できればWebGPUによる字形照合を優先**します。
対象は元のモード4の候補字形評価のみで、顔認識、輪郭、272文字パレット、複数行組版、全体評価は正規のJavaScriptを維持します。
GPUとCPUの浮動小数点精度が異なるため**選ばれる文字の完全一致は要求しません**。
スコアが異常な場合のみC++の元式へ戻し、それも使えない場合は正規JSのCPU計算へ戻します。

## Windows 10/11 x64 の使い方

1. `TASL-Faithful-PC-Boost-GPU-Windows-x64.zip` をフォルダーに**すべて展開**する。
2. 旧PCブーストのEXEが起動している場合は、作業を完了・保存してから閉じる。
   ※両方は同じポート39083を使うため同時に起動できません。
3. `TASL-Faithful-PC-Boost.exe` をダブルクリックする。
   PythonやNode.jsの追加インストール、管理者権限は不要。
4. 標準ブラウザーが自動で開く。開かなければ、
   同じPCで `http://127.0.0.1:39083/` を開く。
5. 「動画 → TSL」で設定と動画を選び、変換。
   PCブーストに自動でチェックが入る（Windowsのブラウザーで起動時）。
   「MP4へ直接変換」で音声付きH.264 MP4を書き出せます。

## 今回の重要な保証

- **正規版の字形選択・輪郭抽出・顔認識・組版の処理を使用します。**
  1フレームを256階調などに単純置換した別のレンダラーではありません。
- 文字変換中の字形候補スコア計算は**GPU（WebGPU）を優先**。
  GPUは元の字形評価に準じるfp32計算をし、浮動小数点誤差による文字の差を許容。
  実GPUが利用不能・数値が大きく破綻した場合は、正規式のC++へ自動切替。
  C++経路ではCPU参照と数値照合し、異常時は正規JavaScriptへ戻ります。
- C++フォールバック側では、テストしたフルHD/PC-98実寸を含む3ケースと実動画→TSL変換で
  正規版と文字列・TSLバイナリの完全一致を確認。
  GPU側は字形の完全一致を要求せず、輪郭・組版の品質評価と異常値検知で確認。
- ただし、すべての動画・端末での完全一致や速度向上を保証するものではありません。
  字形評価の高速化が期待できても、顔検出・全体組版など正規の重い処理は残ります。
- **前の別アルゴリズム版の13分予測は、この正規版には当てはまりません。**
  GPU上の実際の速度はGPUドライバー・文字密度・動画内容に依存し、実測で判断してください。

## GPU / MP4

- **モード4の文字変換処理は実GPUに対応**。ブラウザー内のWebGPUコンピュートシェーダーで
  字形照合を並列処理します。画面の加速表示が「GPU文字照合（WebGPU）」なら
  文字変換工程でGPUを使っています。タスクマネージャーでは「Compute」系グラフを確認。
  GPU未対応や検証失敗時の表示は「正規アルゴリズム C++文字照合」またはCPU処理です。
- MP4書き出しのH.264圧縮は、GTX 1050 Tiで使用できる
  **FFmpeg 8.1.2 / NVENC** を優先します。
  実際に1フレームをエンコードするテストで利用可否を判定し、
  使えない環境では**libx264(CPU)**へ切り替えます。
  画面に実際のエンコーダーが表示されます。
- 音声は元動画から取り出してAACで合成します。
  MP4化で**正規版が作成したTSLの文字選択は変更しません**。
- MP4書き出しはWindows標準の字形描画(GDI)とFFmpegを使用。
  **文字変換はGPUのCompute系、MP4圧縮はVideo Encode系**が負荷を受けます。
  GTX 1050 Ti実機での速度向上率は未測定です。

## 仕様・制限

- 元動画は、ブラウザーから同じPCの `127.0.0.1:39083` へ送信。
  動画フレームや映像内容を外部クラウドへアップロードしません。
- 正規モード4の顔・物体認識用MediaPipeモデルは初回にネット接続で取得します。
  モデルが取得できない場合のふるまいは正規版と同じです。
- 最大入力2GB・4K・2時間、最大10,000文字画面・192MiBのTSLに対応。
  長い動画では正規版同様、フレーム数上限に合わせたfps自動調整があります。
- 正規版の16画面単位の途中保存・再開を維持。PC独自の別形式には変更しません。
- 一時ファイルは `%LOCALAPPDATA%\TASL-Faithful-Boost` に保存。
  完成したMP4の保存後、不要になった一時素材はこのフォルダーから整理できます。
- Windowsでの自動テストはWindows GitHub Actionsランナー上のChromeを使用。
  ソフトウェアWebGPUテストではGPU経路・字形差の許容・大きな破綻時のC++復旧を確認。
  **GTX 1050 Ti実機でのGPU動作・性能・画質はまだ未検証です。**
- このポータブルEXEにはコード署名がありません。
  ZIPのハッシュ値を確認したうえで使用してください。

## 技術的な検証

ソース: `public/tsl-artisan-engine.js` (正規モード4)、
`native-boost/mode4_score_exact.cpp` (同じ候補評価式)、
`public/tsl-mode4-native-exact.js` (実数精度と照合)、
`native-boost/mp4_native.py` (GPU/CPU MP4変換)。

既存の正規画像を使ったPC版とWeb版の文字列比較および
音声付きMP4検証のスクリプトは `tests/` にあります。
