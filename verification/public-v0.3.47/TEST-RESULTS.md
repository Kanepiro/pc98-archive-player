# v0.3.47 検証結果

2026-11-18。v0.3.46正式タグを基準に実装し、v0.3.47-rc.1で以下を検証。正式版は版番号・配布案内・従来のWindows標準ポート/保存先を反映したもので、変換アルゴリズムの変更はありません。

## 実施環境と試験

- Windows 10 Pro 19045 / AMD Phenom II X6 1065T / RAM16GB / GTX1050Ti。Chrome157.0.8103.79、Edge157.0.4341.60。ブラウザーはPlaywrightによるヘッドレス自動操作。
- 単体テスト: Windows110、Web103、計213件合格。
- 6方式（モード1/2/3/4の60/40/30）×6出力プリセットをWindows/Webで確認。TSL保存・読込、旧TSL、中断再開、手動値復元、プレビュー、MP4。
- モード1/3/60pxは、同条件・同経路でv0.3.46のTSL・描画・MP4全フレームデコード後ハッシュと一致。
- MP4全編デコード: Windows51＋Web51＋長尺1＋比較4＝107本。H.264/8bit/yuv420p、指定解像度、実フレーム数、faststartを確認。候補の音声付き出力はAAC-LC。
- 長尺: 約215.411秒FHD素材、モード2、30fps、6463フレーム。出力1920×1080、215.433333秒。音声215.410998秒。5/105/210秒付近のPCM波形の最良ラグはいずれも0ms、相関0.99975以上。JSヒープ最大12.95MiB（全プロセス合計ではない）。
- モード4: 3サイズ×4場面でGPU/JS CPUの文字・配置が一致。GPU通信失敗の注入後もCPU出力へ復帰。
- PWA: v0.3.46からキャッシュ更新、旧チェックポイント/保存値の保持、全6方式のオフライン変換。
- Windows EXEアイコン: 元ICOの16〜256px画像と埋込みリソースの内容一致。

## 画質

実動画（アニメ）1本の23場面で、モード2の24px実描画濃度MAEは0.075016→0.051438、平均31.43%改善。グラデーション・白フラッシュ・暗転の3場面では悪化したため、全素材での改善を保証しません。

自動補正は淡色・暗部・逆光・低コントラスト・通常×6方式、Windows/Web各30組。選択結果は各組の中立値の評価を下回らず、両版の選択設定は30組とも一致。旧自動設定が上回る場面、淡色・ぼけ・細線の欠落は残ります。独自指標だけで人の見やすさを保証するものではありません。

## 性能の扱い

同一1.209542秒、1440×1080入力→24fps30フレーム、旧新各3回を交互順で測定。他作業との並行負荷があり、Windowsモード3ではGPUからCPUへ切り替わった試行を含みます。普遍的な高速化倍率としては扱いません。TSL工程・MP4工程・総時間、取得待ち・キャプチャ・変換呼出しを分離して記録。Windowsエンコード単体は事前に用意したNV12で別測定。詳細数値はTEST-RESULTS.jsonを参照してください。

## 未検証・制限

Windows 11、Android/iOS、Safari/Firefox、他のCPU/GPU・ドライバーは実機未検証。モバイル390×844表示はエミュレーションです。実写・複数作品、全モードの長尺、全プロセス合算メモリ、Webエンコーダー単体時間は未評価。NVENC probe失敗後のlibx264出力を確認しましたが、NVENC成功経路と実ドライバークラッシュ/WARPは未検証です。Explorerの小/大アイコン目視は未完了（リソース内容確認は実施）。

既存の出力上限・ブラウザー制限は維持しています。TSLを開き直したMP4は元動画音声を持たず無音です。低FPSの網羅試験はAPI経由2fpsで行い、旧来のWindows非モード4は既存の最小5fps処理により7フレームとなるため、通常の24fps試験と区別しています。
