# モード別ベンチマーク報告書

## 比較条件

Windowsは公式 windows-v0.3.44（3f0bd408d3e6f47d1e0ea43ccff33265bcf15b94）と候補 v0.3.45-rc.1。Web/PWAは公開mainの aa20464353766735ccf082a10d3344122eec2120 とその候補。ULTIMATE IIは改修参考であり、この倍率の比較元ではない。

Windows: Windows 10、AMD Phenom II X6 1065T、GeForce GTX 1050 Ti、6コア。DirectCompute変換・GPU文字描画・libx264 CPU圧縮。現在のドライバーではNVENC初期化が失敗するため、公開版と同じCPU圧縮へ移行した。

Web/PWA: Intel Core M-5Y10c（2コア4スレッド）、Linux ChromiumのCPUフォールバック。GPUを無効化し390×844のモバイル表示で測定。Android/iOS実機の性能ではない。CPU・OS・ブラウザーの詳細はenvironment資料を参照。

Windowsは機能試験と短尺予備試験の後、アプリホストを常駐させて測定した。OS・shader等のキャッシュがある通常使用時の条件で、Chromeのプロファイルは試行ごとに新規作成した。再現環境の初回起動・キャッシュ状態によって時間は変わり得る。

Windows素材は1920×1080/24fps、短尺2.005秒・中尺22秒・長尺120秒。Web素材は320×180/15fps/2.2秒、640×360/24fps/8秒、480×270/30fps/30秒。追加機能検証は480×270/30fps。明暗、色、動き、ガンマ等の設定差は品質資料で別検証。

短尺・中尺は複数回の中央値。全試行の最小・最大・個別値をCSV/JSONに残し、外れ値を除外していない。Windowsは短尺3回・中尺2回・長尺1回。Webは短尺4回（HTMLVideo先読み撤回後の全試行再測定）・中尺2回・長尺1回。単発の長尺値は傾向確認用。

表の時間は秒。倍率は「公開版の中央値 ÷ 候補版の中央値」。TSL変換とMP4完成までの総時間を分離する。各区間を個別に中央値化するため、区間中央値の和と総時間中央値は一致しないことがある。

## 解釈と測定限界

モード3はWindowsのGPU状態・作業領域再利用、行ごとのDP、CPU側のバッファ再利用で改善。モード4は公開版の特徴量と照合精度を保ったSSE2・マルチスレッド前処理、GPU照合、転送削減で改善した。モード1/2はデコード・取得待ちの比率が大きい。特にWebの小さな差は測定ばらつきと同程度であり、大きな高速化を実証したとは扱わない。

WindowsのMP4は共通フレームの圧縮前画素が一致する。短尺素材では従来欠落していた最後の1フレームを保持したため、末尾の圧縮結果・再生長も変わる。画質設定は変更していない。厳密な比較と理由はQUALITY-AND-STABILITY.mdを参照。

CPU使用率は論理CPU全体を100%としたアプリ・試験ブラウザーのプロセスツリー合計。RSSは各プロセスの常駐量の合計で共有ページを重複計上し得る。WindowsのPrivate Bytesも生データに保存。GPU使用率・VRAMはnvidia-smiのGPU全体値で、デスクトップや他の待機プロセスを含み、候補単独の専有量ではない。

HTMLVideo先読みを撤回後、Windowsモード1〜3の候補18試行を更新し、Webは公開版・候補とも全56試行を再測定した。Windows公開版の測定と、実行経路が変わらないモード4の既測定値は保持。初回候補の速い値はこの集計に混ぜず、失敗を含む旧データを検証ZIPに残した。資源記録がない場合はnullとし推定値で埋めない。

採用した最終構成では120秒Windows長尺と30秒Web長尺で停止・TSL不一致は検出されなかった。無制限の長さ、全機種のメモリ・温度・消費電力、熱による速度変動は保証していない。発熱・電力は実測していない。

生データ: benchmark-runs.csv/json、集計: benchmark-summary.csv/json。元のframe単位timing、CPU/RAM/GPU資源記録、成果TSL/MP4は検証アーカイブに保存。
