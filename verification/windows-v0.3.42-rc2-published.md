# Windows ネイティブ版 v0.3.42-rc2

2026-11-14（日本時間）、ユーザーのWindows 10 / GTX 1050 Ti環境での変換動作報告と公開依頼を受け、同じZIPを正式な最新配布に切り替えました。バージョン末尾のrc2は、動作報告のあるビルドを正確に識別するため維持しています。

- v0.3.41の修正を継承：モード4の自動ズーム、定型の顔への描き直し、顔の外の輪郭消去を修正し、元映像の構図と輪郭を保持します。
- 字形データのGPU常駐、最大10フレームの固定バッファ、作業領域の再利用、変更部分だけの転送を追加しました。追加常駐領域は256MiB以内で、確保できない場合は従来と同品質の処理へ切り替えます。
- 272文字パレット、評価式、探索回数、解像度、フレームレートを維持。WindowsネイティブのDirectCompute / DirectMLを使用し、WebGPUには依存しません。
- スマホ版のプログラム・設定・URLは変更していません。

## 確認済みの範囲

Windows CIではWARPソフトウェアGPUで、元のv0.3.41との文字列・評価値・TSL・MP4の一致、リングの周回・時間方向の状態・ジョブ分離、確保失敗時の同品質切り替え、梱包EXEを確認しました。

Windows 10 / GTX 1050 Tiのユーザー実機では、ネイティブGPU・DirectMLの処理表示と変換進行を確認し、「特に問題なく動いている」との報告を受けています。これは全機種・全工程の実機検証完了を意味しません。実機の改修前後の速度比較とMP4/NVENCの最終確認は未完了です。

CIの同条件・全8フレーム変換は16.2300秒から15.9738秒（約1.6%短縮）でした。別の23フレーム組版試験ではGPU更新APIに渡したデータ量が10,126,532バイトから4,416,732バイト（約56%減）です。物理PCIe転送量や実GPUの高速化率ではありません。大幅な高速化は未確認です。
